# Fine Dining Lab · 分子级摆盘工坊

像搭积木一样创作 fine dining 菜品的精致单页网页。丝网印刷（半调网点）风格的 2D 摆盘，
基于真实高级餐厅数据的评分、风味分子图谱推荐、名厨菜品匹配，以及手机竖版美图导出。

**在线体验**：启用 GitHub Pages 后见 `https://yaosiyuan43.github.io/fine-dining-lab/`

## 特点
- **搭积木创作**：81 种食材 / 20 种技法 / 18 种器皿，点选叠加、拖拽摆盘。
- **有据评分**：基于真实搭配学的合理性评分 + 主厨点评 + 六轴风味雷达。
- **风味分子图谱**：依据 food-pairing 假说（共享香气分子）给可解释的搭配推荐。
- **名厨菜品匹配**：搭完在 58 道真实名菜库里找最相近的一道，附餐厅 / 主厨 / 故事。
- **丝网印刷美术**：Canvas/SVG 半调网点渲染，暗调聚光氛围。
- **导出**：单菜品卡 + 整份菜单，手机竖版 PNG。

## 运行
`index.html` 完全自包含（无外部依赖），**双击即可用浏览器打开**，或部署到任意静态托管。

数据与搭配均有现实依据；创新建立在依据之上。
